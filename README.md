# 🦓 ZEBRA 카페 지도 앱

> React & Spring Boot 기반 개인 프로젝트 – 카페 추천 및 지도 서비스

---

## 📌 프로젝트 개요
- **기간** : 2025.08.11 ~ 2025.08.25  
- **목표** : React와 Spring Boot를 활용한 카페 지도 서비스 구현  
- **개발환경** : React (Vite, JSX), Spring Boot, MyBatis, MySQL, CSS, Figma  

---

## 🎯 주요 기능
1. **인트로 & 로그인**
   - 앱 시작 인트로 화면 및 사용자 로그인 (비밀번호 문제 해결)  
   - 모든 페이지에 **뒤로가기 버튼** 제공  

2. **TOP 카페 추천**
   - 매출/리뷰/인기 순위별 카페 추천  
   - 카페 이름 아래 대표 음료 설명 추가 ☕  
   - **`+` 버튼 클릭 → 카카오 지도 바로 연결**  

3. **주변 카페 지도**
   - Kakao Map API 기반 현재 위치 주변 카페 표시  
   - 원하는 카페 검색 시 지도 내 결과 표시  

4. **카페 상세 카드**
   - 대표 메뉴, 가격대, 좌석/콘센트 여부, 운영시간, 혼잡도 표시  
   - 리뷰 분석 요약 제공 (예: “조용해서 공부하기 좋아요”)  
   - **네이버/구글 API** 연동 또는 크롤링 기반 실시간 혼잡도 표시  
   - 유저 **체크인 피드백** 가능 (“널널해요 / 북적여요”)  

5. **SNS & 공유 기능**
   - 특정 카페 하이라이트 → **카톡/인스타 공유 버튼**  
   - 인스타그램에서 많이 태그된 “핫플 카페” 강조  

6. **부가 서비스**
   - 제휴 카페 전용 쿠폰 (예: 아메리카노 500원 할인)  
   - 첫 방문 체크인 시 **포인트 지급 & 적립**  
   - 개인화 추천: 사용자가 다녀간 카페 기반 추천 제공  
   - **전화 / 길찾기 / 예약 / 인스타그램 열기** → 앱 내 직접 연결

## 🛠 담당 역할
- React 컴포넌트 설계 (인트로, 로그인, TOP 카페, 지도, 검색)  
- CSS를 활용한 UI/UX 최적화 및 반응형 레이아웃 구현  
- Kakao Map API 연동 및 카페 위치/검색 기능 구현  
- 검색 기능과 지도 데이터 연동
