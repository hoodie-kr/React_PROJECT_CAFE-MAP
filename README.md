+ 누르면 카카오지도로 바로 이동하기
모든 페이지에 뒤로가기 버튼 추가


- 하단 카드에 대표 메뉴, 가격대, 좌석/콘센트 여부, 운영시간, 혼잡도 표시
- 리뷰 분석해서 한 줄 요약(“조용해서 공부하기 좋아요”, “사진 찍기 좋은 인테리어”) 제공
-네이버/구글 API 연동 or 크롤링으로 실시간 혼잡도 표시

유저들이 직접 체크인하면서 “지금 자리 널널해요/북적여요” 피드백 남길 수 있음
-특정 카페를 지도에 하이라이트 → “친구랑 공유” 버튼으로 카톡/인스타 스토리에 바로 올리기

인스타에서 많이 태그된 “핫플 카페” 지도에서 강조
-제휴 카페가 있으면 앱 유저 전용 쿠폰 (예: 아메리카노 500원 할인)

“첫 방문 체크인 시 적립 포인트 지급”
-유저가 다녀간 카페 기반 개인화 추천 (ex. “네가 좋아했던 노트북 하기 좋은 카페와 비슷한 곳”)

-카페 카드에 바로 → 전화, 길찾기, 예약 링크, 인스타그램 열기

외부로 안 나가도 앱 내에서 바로 연결
